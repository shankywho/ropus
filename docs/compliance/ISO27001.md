# ISO/IEC 27001:2022 Information Security Management System (ISMS)

ROPUS implements the ISO/IEC 27001:2022 Information Security Management System framework across its AI infrastructure.

---

## 1. Information Security Policies & Risk Assessment (Clause 6.1)
- Continuous threat modeling across automated transaction evaluation pipelines.
- Multi-region disaster recovery with automated RPO $< 1\text{ second}$ and RTO $< 30\text{ seconds}$.

---

## 2. Supplier & Third-Party LLM Provider Governance (Clause 8.15)
- Automated cost and token governance across external LLM inference providers (Anthropic, OpenAI, Local LLaMA).
- Fallback cascades ensuring no single provider outage impacts real-time risk decisioning.
